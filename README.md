# Omarchy Roadster Theme

Omarchy theme celebrating the new Tesla Roadster — aerospace-inspired, light, and precise.

**Roadster** is a light-mode Omarchy theme honoring the second(third?)-generation Tesla Roadster. Inspired by its Ano White finish, gold-glazed glass, and SR-71 / F-35 design language, it features:

- Warm off-white and cream backgrounds
- Muted bronze / warm-brown accents
- High-contrast dark foregrounds for readability
- Wallpapers of the Roadster in its striking aerospace form

## Installation

```bash
omarchy theme install https://github.com/steve-lohmeyer/omarchy-roadster-theme
```
Or paste the URL in the Omarchy menu under Install → Style → Theme.
